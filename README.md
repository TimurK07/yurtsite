# Юрта Казахского ханства

3D-сайт на Three.js. Без сборки: index.html + three.min.js + папка assets.

Деплой: `npx vercel --prod` в этой папке, или GitHub → Vercel (Framework: Other, Build: пусто, Output: .).

Локально: `npx serve .` (просто открыть файл двойным кликом не получится — браузер не загрузит картинки без сервера).

Управление: мышью осмотреться, ← → предметы, Esc общий вид.
